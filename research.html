How the all-in-one platforms fit it all in one

Justin asked how Webflow makes everything one product, and pointed at Stripe Projects, Appwrite and Wix Studio. The short answer: each one owns a single source of truth and bolts every service onto it, so you never leave one place to design, store, host and pay.

The four, in one line each

Provisioning from the terminal

Stripe Projects

  • A Stripe CLI plugin that attaches hosting, a database, auth, AI and analytics to a project.
  • Writes the credentials into a local .env and keeps state in .projects/.
  • Can rotate credentials and upgrade tiers; payment method added once.
  • Built to be handed to coding agents.

Borrow: one command spins up the whole stack, and keys never get copied by hand.

Open-source backend

Appwrite

  • Auth with 30+ sign-in providers, teams and roles.
  • Databases with row-level permissions, file storage, serverless functions.
  • Sites: hosting with SSR, custom domains and DDoS protection.
  • Messaging and a Terraform provider for the whole setup.

Borrow: every service shares one permission model, so access rules are written once.

Visual site builder

Webflow

  • Design canvas, CMS and hosting in one editor.
  • GSAP-powered interactions, including scroll and text effects.
  • Webflow Cloud runs full-stack Next.js or Astro apps with SQLite, key-value and object storage.
  • Cloud deploys no longer require republishing the site.

Borrow: the design canvas is the source of truth; CMS, motion and hosting read from it.

Agency site builder

Wix Studio

  • Built for agencies running many client sites.
  • No-code CMS, a built-in IDE and APIs for custom front- and back-end code.
  • Content Mode: clients edit words and images while the design stays locked.
  • Client kits and automatic reports for handoff.

Borrow: a locked "content mode" so a client can edit safely without breaking the design.

What we should build to beat them (and be more fun)

  1. The secret key manager first. Like Stripe Projects: every service's keys land in one vault, scoped per desk, rotated in one click, never pasted by hand. That is the first thing Justin asked for.
  2. One source of truth: the JSON scene recipe. Like Webflow's canvas. Pages, motion, CMS and 3D scenes all read from the same recipe, so changing it changes everything.
  3. One permission model. Like Appwrite. Desks, agents and people share the same roles, so "who can touch what" is written once.
  4. A locked content mode for clients. Like Wix Studio. Clients change words and pictures by typing or speaking, and the design can't break.
  5. Make it a place, not a dashboard. None of the four is fun. The theater, the desks and the storyboard are the difference: you watch the work happen.
