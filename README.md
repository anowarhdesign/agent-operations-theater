# Agent Operations Theater

A concept demo of a cinematic room where AI agents work at desks (Publishing, Video, Manufacturing, Merchandising, Secret keys) and feed the Scene Engine on a big screen.

- **3D demo:** `index.html`. Orbit the room, open any desk's screen, zoom in, run commands, and browse the storyboard and ray-traced renders.
- **Prototypes:** `vault.html` (secret key manager), `book.html` (The Book of UI Math), `research.html` (all-in-one platforms brief).
- **Project Link Hub:** `hub/`. Links to everything for the Theater, HoyOS and Between Gigs.
- **Motion video:** `video/agent-theater-concept.mp4` (55 s, 1080p).

Built with three.js r128. Lighting is baked in Blender Cycles, and the models are Draco-compressed GLBs stored as base64 `.glb.txt`.
